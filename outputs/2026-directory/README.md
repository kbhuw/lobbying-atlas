# Federal lobbying directory — 2026

The CSV and JSON contain all 18,036 directory entries with reported activity in 2026. They are name groups, not a verified count of distinct legal entities or lobbying meetings.

`individual_review` identifies the 18036 entries reviewed individually so far. `confirmed` refers to identity and core profile information; it does not mean every field, including the logo, is complete. `partial` and `unresolved` preserve gaps. The remaining entries are explicitly marked `not_individually_reviewed`.

`source_tier` distinguishes individual research, automatic registry matches, descriptions reported in filings, and pending entries. A `filed` website is reported in a tax return and may be historical. Site icons are distinguished from logos. Sources and original filing names are retained. No missing field should be interpreted as proof that an organization does not exist or has no website.

The full research task is unfinished. The export is a structured snapshot, not a claim that all entries are verified.

The `resolved-organizations.json` and `.csv` files contain the current built local directory after verified splits and merges, filtered to 2026. JSON retains filing assignments, source records, and identity-split evidence. The original `organizations` files retain the fixed source-name inventory for audit. Local exports may include changes not yet published; see publication status in `progress.json`.
