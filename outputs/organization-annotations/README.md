# Federal lobbying organization annotations

This is an incremental research export, not a completed directory review.

- profiles.json contains individually examined entries; unresolved identities are explicitly labeled.
- progress.json records snapshot coverage across 76,884 directory name groups.
- Each profile supplies source URLs and the claims they support. Ownership is dated independently from lobbying activity years.
- Automatic SEC/IRS matches and filing-provided descriptions are separate evidence tiers, not individual research.
- Missing ownership or identity evidence remains unknown. Public benefit corporation does not mean publicly traded.
- Name groups originate from filing-name cleanup; full corporate identity and historical aliases are not all verified.

The hourly schedule is paused. This export was produced during the accelerated research pass using lighter subagents, parent review and bulk source matching.
